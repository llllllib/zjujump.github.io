# 在线排行榜

直接打开 `浙大跳一跳.html`，或通过静态网站托管整个项目；无需安装依赖。点击右上角“排行榜”查看前 100 名。游戏失败或通关后，在结果卡片输入昵称并提交成绩；可以跳过提交继续游戏。

配置在 `leaderboard.js` 顶部：`API_URL`、`LEADERBOARD_TAG`、`API_USER`、`API_SECRET`。当前使用 HTTPS 地址访问同一个 TinyWebDB 服务，避免 HTTPS 网站出现混合内容拦截。榜单 tag 固定为 `zju_tiaoyitiao_leaderboard_v1`。

该站实际 API 需要 `action=get/update`，返回 `{tag: value}`。代码同时发送需求中的 `method=getvalue/storeavalue` 和服务需要的 `action`，兼容 `VALUE` 字段、标准 App Inventor 的 `['VALUE', tag, value]` 及该站的返回格式。若更换为只接受 `method` 的服务，将顶部 `API_ACTIONS` 改为 `null`。

每条记录为 `{nickname, uid, score, createdAt}`。首次联网成功时，生成 8 位小写字母和数字的 ID，与服务器返回的所有 ID 比对，无冲突才保存到 localStorage。已有 ID 永久复用，不因榜单中存在相同 ID 而重新生成；榜单中的这条记录就是该玩家自己的记录。初次联网失败时暂不保存未经核验的 ID，刷新或提交时会再次尝试。

提交会读取整榜、按 ID 合并最高分、按分数降序和达到分数时间升序排列、截取 100 条，再把 JSON 数组整体写回。更高分会更新昵称和时间；同分或更低分保留原纪录。写后重新读取验证，网络失败或并发覆盖时最多自动重试一次。被正常挤出前 100 名会显示相应提示。0 分、非整数、负分和超过 99999999 的分数会被拒绝。同一 ID 的手动提交间隔至少 3 秒，自动重试属于同一次提交。

昵称、玩家 ID 及最后提交时间保存在浏览器本地。昵称允许重名，长度为 1–16 个字符，仅限中英文、数字、下划线和连字符；输入中的 `#` 会移除并提示。榜单用 `textContent` 创建表格内容。网络或本地存储不可用会显示错误，不影响游玩。

TinyWebDB 没有原子更新，这种重读重试只能缓解并发覆盖，不能保证绝对无丢失。纯前端的账号配置和分数校验可以被查看或修改；这份实现适合轻量校园榜单。清除本地存储或换浏览器会产生新玩家 ID。

验证命令（Node.js 24，无第三方依赖）：

```powershell
node --test --test-isolation=none tests/game-core.test.cjs tests/leaderboard.test.cjs
```
